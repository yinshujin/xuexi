# xuexi：家庭小学数学 AI 学习 App

给自家孩子用的小学数学补习和巩固应用，按深圳北师大版课本同步，以专项练习为核心，配合 AI 讲解课和技巧微课。支持华为平板（HarmonyOS 4.x）、安卓手机、iPhone、Mac 和 Windows。AI 内容由脚本提前生成，App 运行时不调用模型。讲解课生成使用开源项目 [OpenMAIC](https://github.com/THU-MAIC/OpenMAIC)（MIT）。

当前阶段是方案设计，详见 [docs/solution-plan.md](docs/solution-plan.md)。MVP 先做二年级和四年级数学。
